# Memory Guidelines

When interacting with memory and skills, adhere to the following principles:

- **Store verified information**: Only save facts and rules that have been confirmed accurate. Avoid storing untested hypotheses.
- **Prefer reusable procedures**: Focus on recording generalized, reusable procedures rather than one-off, project-specific scripts.
- **Avoid temporary reasoning**: Do not store transient variables, intermediate reasoning steps, or states that are only relevant to the immediate task.
- **Deduplicate memories**: Before storing a new memory or skill, check if similar information already exists. Update or consolidate with existing entries rather than creating duplicates.
- **Update stale skills**: Actively identify and update skills or memory entries that are outdated, deprecated, or no longer functional.
- **Preserve environment facts**: Record important, persisting facts about the environment, project structure, or dependencies.
- **Record failure lessons**: When an approach fails, document the failure and the learned lesson to avoid repeating the mistake.
